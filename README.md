# cmsc408-sp2025-hw8

Homework 8 - World Bank Indicator Analysis

This assignment focuses on analyzing real-world data from the World Bank's World Development Indicators (WDI) using SQL and Python inside a Quarto report. The main objective is to explore and manipulate data from a large wdi_country table containing country-level and region-level indicators such as income category, region, and status (country vs. non-country).

Key learning goals include:

Writing and executing SQL queries to filter, group, aggregate, and transform data.

Creating custom summary tables and crosstabs using advanced SQL techniques like CASE, GROUP BY, and subqueries.

Interpreting patterns in global development data, such as how countries are distributed by region and income category.

Correcting data inconsistencies (e.g., income classification errors).

Reflecting on data analysis practices and SQL skills.

In the end, students generate a clean and reproducible HTML report combining data queries and narrative reflection.
